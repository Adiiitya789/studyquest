# StudyQuest 📚

A minimalist study timer and productivity tracker designed to help you stay focused, build habits, and earn rewards. Start a session, listen to ambient sounds, and climb the global leaderboard!

## ✨ Features

* **Stay Focused:** Earn coins for every minute studied and unlock milestone badges based on your total hours.
* **Live Global Leaderboard:** See who else is currently studying and track weekly top performers in real-time.
* **Ambient Soundscapes:** Built-in lofi beats and rain sounds with independent volume controls to keep you in the zone.
* **Session Protection:** Native browser warnings prevent you from accidentally closing or refreshing the tab and losing your progress.
* **Cross-Platform (PWA):** Installable directly to your Android or Desktop home screen for a native app experience.

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript, Vite, Tailwind CSS, Lucide Icons
* **Backend & Auth:** Supabase (PostgreSQL, Google OAuth, Email Login)
* **Hosting:** Vercel 

## 🚀 Getting Started

To run this project locally on your machine, follow these steps:

1. Clone the repository and open it in your terminal.
2. Run `npm install` to install all necessary dependencies.
3. Create a `.env` file in the root directory and add your Supabase keys (`VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`).
4. Run `npm run dev` to start the local development server.
